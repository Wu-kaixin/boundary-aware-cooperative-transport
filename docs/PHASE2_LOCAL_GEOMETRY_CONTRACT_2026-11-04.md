## 2. 三种局部模型比较

令真实边界弧为 Γ，两个测量端点为 a_hat、b_hat，F 为两者间线段。假设各端点欧氏误差不超过 ε；这是条件事件，当前 3σ 并不是确定误差界。

| 局部模型 | 充分误差界 d_H(Γ,F) ≤ E | 必须另外证明的条件 | 本轮判断 |
| --- | --- | --- | --- |
| 弧长参数、光滑曲率界 | ε + κ Lbar²/8 | 同一连接弧、真实弧长 L≤Lbar、曲率范数≤κ | 可解释光滑段；不能跨未计入角点 |
| 扫描角参数 q(θ) | ε + Mθ Δθ²/8 | 同一连续可见分支、弧度参数、全段 ‖q''(θ)‖≤Mθ | 可用，但掠射时可能过度保守；Mθ 不是曲率 |
| 弧长参数、切向总变差 | **ε + κ Lbar²/8 + Lbar J/4** | 同一连接弧、Lbar、连续曲率 κ、全部剩余切向变化总量 J | 推荐作为统一的条件性表述；当前前提未获认证 |

这些是充分条件，不声称数学上最弱或必要。插值误差和测度积分是标准工具；本轮推导用于审查本项目的适用条件，不作为原创控制理论。分段线性插值的误差阶与端点扰动稳定性已有教材论述；此处具体向量范数常数由下文直接推导。[Driscoll & Braun, §5.2](https://tobydriscoll.net/fnc-julia/localapprox/pwlin.html)

### 2.1 统一误差界与证明

令 q:[0,L]→R² 为弧长参数化的连通边界弧，L>0，q' 为有界变差函数，并存在分解

```text
Dq' = g(s) ds + ν,
‖g(s)‖ ≤ κ，|ν|((0,L)) ≤ J，L ≤ Lbar。
```

ν 包含全部剩余测度，不能遗漏奇异部分。有限分段光滑边界可把角点的切向跳变纳入 ν；单个转角 φ 的贡献是 2|sin(φ/2)|，各角点取范数后累加，不能用凹凸转角抵消。κ 的单位是 m⁻¹，J 无量纲，Lbar 单位 m。

设 ℓ(s)=(1−s/L)q(0)+(s/L)q(L)。零端点 Green 核

```text
G(s,t) = min(s,t) [L−max(s,t)] / L,
q(s)−ℓ(s) = −∫ G(s,t) d(Dq')(t),
∫ G(s,t)dt = s(L−s)/2 ≤ L²/8,
max_t G(s,t) = s(L−s)/L ≤ L/4。
```

因此 ‖q(s)−ℓ(s)‖≤κL²/8+LJ/4。测量线段上同参数 s/L 对应点与 ℓ(s) 的距离不超过 ε。这个参数同时遍历整条弧和整条测量线段，故得到**双向 Hausdorff 界**

```text
E = ε + κ Lbar²/8 + Lbar J/4。
```

这也意味着任意查询点到这条弧和线段的无符号距离之差不超过 E。要解释成整个物体的有符号安全距离，还需外部侧判定、所有危险边界的覆盖及运动期间有效性。此公式本身没有给出这些性质。

### 2.2 两个易错替换与一个参数化限制

**弦长不能直接当作弧长。** 固定解析例取单位圆两端点角差 0.1 rad，但连接它们的是长弧。真实弦长 0.0999583 m、弧长 6.1831853 m；错误使用 κc²/8 给出 1.249 mm，而长弧远端距线段 1.9987503 m。正确弧长公式给出保守但有效的 4.7789726 m。这反驳的是“曲率加小弦长自动足够”的推理，并非一个真实回波重放，也不满足未经另证的短可见弧条件。

**含噪弦长需要误差传播。** 若已知真实连接弧长≤Lbar、真实弦长 c，则由椭圆包含关系可得 d_H(Γ,[a,b])≤sqrt(Lbar²−c²)/2。换成测量端点后先加 ε；若仅有测量弦长 c_hat，则根式中应使用 c_low=max(0,c_hat−2ε)。不能把真实 c 直接换成 c_hat。若 c_low>Lbar，则前提不相容，应拒绝认证，不能静默截断负根式。

尤其对两条直边组成的单个直角，真实界为 c/2，安全的测量替换可取 c_hat/2+2ε。c_hat/2+ε 一般不成立：取等长两直边的直角，沿弦方向把两端各向内移动 δ，同时将整条弦向远离角点方向移动 η，取 δ=η=ε/√2、c>2δ，则每个端点误差恰为 ε，但真实角点到测量弦的距离是 c/2+η，超过 c_hat/2+ε=c/2−δ+ε。这个通用欧氏端点噪声反例没有同时建立现有相邻 5° 射线及全部配对条件，不能称为当前传感器准入规则的反例。它排除的是仅凭这两个端点误差条件就宣称认证界成立的推理。当前源码本来也注明有限支持是经验模型。[finite_support.py](../src/dbact/sensing/finite_support.py)

固定等长直角例的两腿各 40 mm，真实弦长 56.5685 mm、准确 Hausdorff 距离 28.2843 mm；统一式的 J=√2、L=80 mm 恰好给出相同结构项。若“至多一个直角”仍允许其余弧任意弯曲，这个两直边结论就不适用。

**角参数的导数界不同于曲率界。** 直线 x=a 的射线交点是 q(θ)=(a,a tanθ)，其曲率为零，但 q''=(0,2a sec²θ tanθ) 在掠射附近很大。边界本身与弦都在同一直线上，几何误差仍为零。因此 Mθ 模型可因切向重参数化而过度保守，不能从 κ 和 5° 扫描间隔直接读出 Mθ。

## 4. 接触预算：仅针对这套强证书

假设一个相同物理间隙确实位于 [d−E,d+E]，要求所有允许间隙均具有正穿入量，即 d+E<r_robot。再令 n 为向外法向，a=−n·u≥0 是向内法向速度，D≥0 为所选分步执行模板的运动需求。给定屏障行

```text
n·u ≥ D − γ(d−E−r_safe) + ρ，r_safe=r_robot−δ_max，
```

两要求同时成立，必须存在

```text
r_safe + E + (D+ρ+a)/γ ≤ d < r_robot−E，
即 2E + (D+ρ+a)/γ < δ_max。
```

这是区间非空的条件；对于该标量模型也是存在某个 d 的充分条件，不保证给定状态 d 满足，更不保证其他约束、接触力或任务。现有常数为 ε=0.03 m、δ_max=0.065 m、γ=8 s⁻¹、ρ=0.02 m/s，得到：

| 在明确条件下 | 严格预算 |
| --- | --- |
| D+a=0，E=ε+结构项 | 结构项 < **1.25 mm** |
| 结构项=0，E=ε | D+a < **0.02 m/s** |
| 角参数式、72 条等角射线、D+a=0 | Mθ < **1.313123 m/rad²** |
| 统一式、两直边单个 90° 角、D+a=0 | Lbar < **3.535534 mm** |

后两行是对各自充分误差上界的预算要求；不能把保守上界超出预算反推真实误差超限。位置、关联、执行和其他建模误差尚未另加，以上已经是这些项为零时的乐观预算。初始外侧安全、几何覆盖和全保持段运动界仍是独立条件。

“所有允许噪声世界都保证接触”强于现有物理任务的实际接触要求。正穿入也不自动推出正法向力，因为接触模型含速度阻尼。此表不能用于声称任何控制器都无法搬运，亦未改变当前速度上限、停止判据或物理参数。

## 5. 信息契约与唯一否证标准

| 所需前提 | 当前实际可得内容 | 本轮审查结论 |
| --- | --- | --- |
| 端点误差事件 | 射线点、原点、σ；历史固定样本存在超过 3σ 的误差 | 只能条件化；不得默认为确定有界噪声 |
| 同一连接边界弧、可见分支 | 相邻 ray_index、同 object_id、测量间距阈值 | 不能独立证明连接弧或排除隐藏特征 |
| Lbar、κ、J | 当前 ScanSupport 没有这些认证字段 | 需要明确局部类先验或新认证机制；不能用拟合残差代替 |
| 全部危险边界覆盖 | 原 near-return 覆盖检查针对已观察回波 | 不等于覆盖全部真实未见边界 |
| 初始安全、法向/外部侧、整个保持段 | 静态行与已保存时间信息；实际执行先移动机器人再推进物体 | 仍需单独的分步执行论证与运动误差界 |

曲线重建文献同样依赖明确的采样/几何条件；固定角分辨率不能自动等同于相对于真实局部特征尺度的充分采样。这是对现有接口的推断，未把重建论文的定理直接移植到 DBACT。[Amenta, Bern & Eppstein, 1998](https://ics.uci.edu/~eppstein/pubs/p-crust.html)、[Bjerkevik, SoCG 2022](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.SoCG.2022.9)

**否证合同：** 若未来声明一种局部准入规则，必须先固定允许形状类、噪声事件、观测与时间模型。每个被准入的射线对都要有可追溯的连接弧、Lbar、κ、J 证书。只需找到一个符合这些已声明允许条件、与观测一致、却违反证书或距离界的场景，就否决该准入规则的安全解释。无法证明前提时必须标记“未认证”，不得以未找到反例作为通过。数学引理是在前提成立时的命题；前提不成立的例子反驳的是准入解释，不是引理。

原隐藏凸起反例继续保留，不为本轮寻找更有利世界。它有一侧已违反初始安全，故只能否定通用当前距离下界，不能用于否定一个明确假设初始安全的保持性定理。新的任何规则仍须另外处理危险边界覆盖及执行时序，不能只通过局部 chord 检查就宣称安全。

## 7. 研究决策与下一阶段建议

正面结果是一个前提明确、兼容实际多边形并可被反证检查的局部模型表述。负面结果是：曲率界本身不够；当前回波不能认证关键前提；误差与接触的强鲁棒预算很窄。光滑椭圆替代实际多边形还会引入明显模型差异。它们收窄了可诚实提出的论文主张，没有建立新搬运算法或论文核心贡献。

主线建议仍为 **R1，但只在显式局部结构条件获得用户批准后继续**。应把下一科学问题写成：“在声明的局部边界类与条件噪声事件下，可认证的局部模型是否能保留足够接触能力，并最终改善完整任务？”这些条件是先验结构知识；“无完整物体先验模型”与“没有任何几何先验”不能混写。完整去中心化仍是独立问题。

备用 R2 可研究已有可行域内的任务方向选择，但不能排除已存在的空集/强制反向状态。如果不接受新增局部结构先验，应放弃 R1 的确定性保证主张，重新审议明确承认安全边界的经验任务机制，而不是暗中换噪声或放宽成功标准。
