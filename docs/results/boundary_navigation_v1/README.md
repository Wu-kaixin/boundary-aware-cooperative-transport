## 范围和下一步

这是同一已使用开发seed下的九个几何/朝向条件，不是独立成功率验证；不能从5/9相等推出等价，也不能把逐帧样本作为独立试验。新增配置无附着、不读物体真值；局部/一跳估计与全队阶段监督的权限分开说明，仍不称完全去中心化。MAS接口保留，所有研究仅仿真，论文题目未改。

停止扩大当前三个控制配置，不继续调参数追成功。优先在已有冻结日志上检查稳定参考地图/关键帧位移估计是否能减小累计偏差，并分别辨别接触不足与错误停止；只有同输入离线核验支持后，再冻结一个新候选和独立预算。不得以评价真值宣布到达，或直接把1.24按形状调到通过。

输入限制：回放的`sensed_points`实际是agent_00的融合地图快照，不能当成全队原始扫描。替代估计器的同输入比较须先从冻结传感器源码、已记录轨迹和随机身份验证重建，并标注重建身份；不能验证时，另定最小原始输入采集预算。本轮没有补造这些缺失字段，也没有启动该项新试验。

G500口径补充：原spacing的椭圆平行案例在311.10秒进入收定，600秒G500通过，但二维终点误差仍为0.580946米，任务不完成。因此本轮spacing的600秒G500为4/9，而旧150秒为3/9；不是改写历史结果或成功阈值。
