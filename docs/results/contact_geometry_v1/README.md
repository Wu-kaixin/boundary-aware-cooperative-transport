## 三类困难不能混为一个问题

1. **圆形的参考点语义。** 局部扫描质心并非圆心，读出其配准平移会混入旋转位移。只用观测点拟合圆形参考中心，保留原配准与准入，确实减少了位移误差；它仍没有证明现有接触控制能完成运输。原参考闭环位移 MAE 为 200.293 mm，修正后为 5.389 mm。这两个闭环误差随轨迹变化；同输入检验另存于本地 readout-screen。
2. **接触距离。** 用最新扫描的局部点集拟合距离，而非直接取最近噪声点；保留融合地图法向及全部安全行。抽样平均误差改善不等于没有离群误差，也不是物理接触证书。实际准入与同一批准入记录上的距离误差见完整表。
3. **终端确认和接触可达性。** 椭圆距离修正臂终点误差约 39.75 mm，曾在物理目标区内连续低速 957 帧（47.85 s），但控制器到达门控从未成立。2 cm 控制到达带与 12 cm 独立任务容差作用不同，原结束规则还要求 HOLD；保留为未完成，详见 [停止核查](ellipse_stop_audit.json)。旧 C 背向三个采样状态的现有接触配置无法提供朝目标且零侧向、零力矩的静态力；这提示接触配置问题，不证明整段任务不可能。

新 C 距离修正臂的末 10 秒还有一条直接证据：211 个名义推手记录中，146 个尚在几何接触之外；106 个同时出现向内命令被 QP 削减、物体行活跃而机器人间行不活跃。见 [终端命令核查](terminal_command_audit.json)。这尚未证明物体约束错误，下一步应追溯活动约束来自哪个观测面；合法阻挡应通过换位解决，不能绕过安全层。
