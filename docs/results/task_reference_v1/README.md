## 实际改变及权限

获取期只积累自己和当前一跳邻居的扫描，临时增加观测间距，至少四个局部模板
有二维及法线支撑后冻结。获取耗时计入总预算；退出后恢复原接触安全半径。
八个带获取阶段的回合均在冻结前零接触、零平移、零旋转，零参考假设在本批次
评价中成立。冻结时间为圆形 1.8 s、L 形 1.7 s、远场 C 20.5 s、远场斜盒 39.5 s。

新读数不继承旧地图的初始化位移和 1.24 倍放大。局部 SE(2) 拟合统一换算到
已知工作区中心 q：`d_q = t + (R-I)(q-a)`，再用几何中位数聚合允许收到的
新鲜消息。q 是共同坐标参考，**不是物体中心估计**。共享阶段监督器还要求
每个新鲜拟合在工作区四角上的最大目标误差不超过原物理容差，且至少四票。
没有使用物体中心、形状、任务 start 或接触真值控制机器人；中心真值仅用于评价。

工作区最坏界只在刚体拟合正确且初始面积中心位于工作区时成立，不能证明配准正确。
理想圆的朝向不可观测试通过，但实际带噪声圆仍产生虚假的旋转信息：最终条件界
约 11.31 m，说明三倍噪声的经验筛选不足以处理圆形对称性。远场 C、斜盒最终
条件界分别约 0.263 m、0.181 m，超过 0.12 m。完整守卫消除了本批次错误 HOLD，
同时使三个回合长期停在 BRAKE；它没有提供可靠的完成机制。

## 补充诊断与后续顺序

固定轮廓探测对四个获取场景的初次支撑和最终模板分别使用同一个 concave-hull
方法。初次支撑的局部轮廓中心误差中位数约为：C 691 mm、斜盒 478 mm、
圆形 538 mm、L 形 658 mm；边界不受扫描支持的比例中位数为 55%–64%。
这否定了本次简单轮廓方案，不能推广为“任何方法都无法恢复中心”。首次探测
误把直接 step 录像的第一帧当初态，已保留并标为 INVALIDATED；v2 补回构造器
初态，并逐条件核对全部局部体素数与原收据一致，没有新增物理回合。

下一阶段应先处理可辨识性和完成能力：对圆形等对称观测分开建模，区分真实
角运动与匹配歧义；在不完整几何下建立可执行的中心不确定集合，或通过主动观测
取得有依据的完整轮廓；同时检查守卫拒绝停止后是否还有可以完成任务的控制动作。
若引入统一尺寸上界，必须明确这是新增任务先验，所有方法共享，不能按物体真值调节。
本批次不追加参数筛选，不启动剩余开发条件或新系统的独立验证来掩盖失败。
