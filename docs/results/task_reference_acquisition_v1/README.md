# 初始参考获取：固定可行性试验

执行于 2026-11-02，整理于 2026-11-03。四个已使用的开发条件，各运行两组，
每组 60 秒，新增 8 个物理回合；**新增搬运完成证据为 0**。

两组均暂时阻止 CONTACT_READY，继续原部署策略。观测间距组把获取期间的
安全半径设为 `robot_radius + 3*noise + 2*max_speed*dt = 0.195 m`；
物理模型、物体和评价参数不变。每个机器人只积累自己及当前一跳邻居的扫描。
支撑判据为至少四个局部模板各有 32 个体素、次轴 RMS 大于三倍噪声、
法线最大角缺口小于 π。这是获取代理指标，不能证明物体中心可观。

| 条件 | 原间距首次支撑 | 原间距此前接触/平移 | 观测间距首次支撑 | 观测间距此前接触/运动 |
| --- | ---: | --- | ---: | --- |
| 近场圆形 | 2.05 s | 0 / 0 | 2.05 s | 0 / 0 |
| 近场 L 形 | 2.05 s | 3 次接触样本 / 0 | 2.05 s | 0 / 0 |
| 远场 C 背向 | 21.05 s | 122 次 / 44.46 mm | 20.55 s | 0 / 0 |
| 远场斜盒 | 37.55 s | 927 次 / 164.50 mm | 39.55 s | 0 / 0 |

“此前”包含首次支撑检查时刻；每十帧检查一次。接触样本按控制帧累加，
不是独立碰撞事件数。真值只用于离线评价，未反馈控制器。

观测间距组在这四个条件首次满足支撑时均未接触，平移和旋转均为零。
但斜盒继续运行到 60 秒后出现 3 次接触样本及 0.002263 rad 旋转。
因此必须在满足条件时冻结并退出获取阶段，不能把 60 秒末模板用于初始静态参考。
增加间距不是无接触保证，每次闭环运行仍须独立检查零时刻假设。

下一阶段采用固定三组对照：原系统、仅获取阶段、获取加新参考。
时间成本计入原 600 秒总预算；初始参考读取不使用任务 start、物体形状或中心。
圆形朝向模糊、局部支撑不等于中心可观、错误匹配均保留为限制。
