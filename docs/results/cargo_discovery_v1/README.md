# BACT：不规则货物与远场位置权限比较

本轮完成近场 132 回合及远场 12 回合固定开发试验，seed 2、最多 600 秒/例。近场安全完成：边界 CVT 31/33；spacing 31/33；nearest 31/33；检测点密度 CVT 1/33。远场：未知位置 3/6 完成、6/6 检测；初始位置提示 3/6 完成、6/6 检测；硬安全失败：未知位置 0/6、提示 1/6。这些是设计条件上的开发结果，不是任意形状成功概率或独立可靠性验证。论文题目未改，只做仿真、无附着。

## 边界 CVT 究竟多解决了什么

| 部署模块 | 原九条件安全完成 | 新24条件安全完成 | 全部33条件安全完成 | 任务完成 | G500 | 硬安全失败 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 边界 CVT | 8/9 | 23/24 | 31/33 | 31/33 | 27/33 | 0/33 |
| spacing | 8/9 | 23/24 | 31/33 | 31/33 | 25/33 | 0/33 |
| nearest | 8/9 | 23/24 | 31/33 | 31/33 | 23/33 | 0/33 |
| 检测点密度 CVT | 0/9 | 1/24 | 1/33 | 1/33 | 1/33 | 0/33 |

- 对 spacing：边界 CVT 独有安全完成 1，对照独有 1，净差 +0/33。CVT 失去的完成条件：u_tray_s0_r90。
- 对 nearest：边界 CVT 独有安全完成 0，对照独有 0，净差 +0/33。CVT 失去的完成条件：无。
- 对 检测点密度 CVT：边界 CVT 独有安全完成 30，对照独有 0，净差 +30/33。CVT 失去的完成条件：无。

未达到相对全部对照的预先开发优势门槛，不能宣称整体算法优越；应按具体条件与指标报告得失。

更具体的次要指标是部署分布，而不是额外完成条件：

| 新24条件，CVT相对 | 未覆盖弧更小 / 更大 | 配对弧长差中位数 | 配对部署时间差中位数 |
| --- | ---: | ---: | ---: |
| spacing | 17/24 / 7/24 | -0.083 m | +0.125 s |
| nearest | 24/24 / 0/24 | -0.522 m | -0.800 s |

差值均为 CVT 减对照，按条件先配对再取中位数，不是两个组中位数之差。弧长来自各方法首次 CONTACT_READY 后真实状态的360点等弧长诊断、0.42米外侧机器人覆盖半径；它不等于 formal caging，也不是同一物理时刻的比较。部署时间代价单列。完整总体及新条件的描述性统计见 [次要配对指标](secondary_metrics.json)。当前证据支持在这些条件下改善边界分布，不能把它改写为完成率优势或动态安全保证。

G500按上表方法顺序分别为27/33、25/33、23/33、1/33，仍是独立的既有合同指标。前三种方法触发 barrier scaling 的条件数分别为4、6、9，总事件数分别为18、9、75；所以“发生事件的条件更少”和“事件总数更少”并不等价，也不能笼统宣称 CVT 对所有安全代价都更优。各回合具体G500失败原因保留在CSV。

比较只改变首次 CONTACT_READY 之前的部署目标，后续运输、位移估计、压力、物理、安全和成功规则共同。原九个 CVT 参考回合的 25 个 replay 数组及原逐帧科学字段全部精确复现；共同安全修复不能计作 CVT 的独有创新。

边界密度的支撑是观测边界的任务方向偏置点，并按弧长、置信度和间隙加权；spacing/nearest 使用同一组边界偏置点但改变目标选择。检测密度 CVT 把支撑改为自身/一跳新鲜检测机器人的位置，保持核宽、背景和总核质量。它受 [Song 等人原式 (5)-(6)](https://arxiv.org/html/2602.19070v2) 启发，但保留本系统公共边界质量与门控，是表示机制对照，不能宣称完整复现或战胜该论文的方法。

本轮没有分别优化各方法的参数，所以比较回答的是固定共同参数下的部署表示作用，不是各方法最佳调参版本的排名。特别是检测密度需要与其原始招募/控制流程一起评价，不能从这一替代接口的失败推断原论文算法必然失败。

对检测密度的完成差同时出现在 CVT、spacing 和 nearest 三种边界目标方法中，因此更直接支持边界目标信息在本流程中的作用，不能单独归功于 CVT 求解器。CVT 相对另外两种边界目标方法目前更明确的证据，是上述部署间隙的条件配对差异；完成数依然相同。

全部条件和指标见[近场 CSV](near_episodes.csv)、[近场可追溯分析](near_analysis.json)、[结果矩阵](near_all_outcomes.pdf)和[配对指标](near_paired_metrics.pdf)。部署图和完成结果必须合看；几何覆盖、物理接触、收定、G500和任务完成不互相替代。

## 未知外形与未知位置分开回答

近场包含原五形状九条件，以及六种货物族、两个几何实例、两个朝向的新 24 条件。均等面积/质量，公开周长、惯量、尺寸；新旧初态层次分开。形状是预先设计的刚体多边形，不是任意形状总体随机样本。[几何图](cargo_geometry_atlas.pdf)。

远场采用圆、斜边箱、C 背向三种几何、两个位置。所有机器人初始扫描为空，最近初始边界距离超过 3.12 米。两臂物理初态相同，只在提示臂提供一次初始位置 token，12 秒 TTL不变；不提供轮廓或后续位姿真值。未知位置 3/6 完成、6/6 检测；初始位置提示 3/6 完成、6/6 检测；硬安全失败：未知位置 0/6、提示 1/6。完整配对见[远场 CSV](far_episodes.csv)、[位置权限图](far_location_pairs.pdf)、[实际过程图](far_full_process.pdf)。发现成功不代表运输完成。

两臂各六例全部检测、达到部署阶段并发生真实接触，但各只有三例完成，G500各为2/6。C背向在位置0由提示帮助完成，在位置1反而是未知位置臂完成而提示臂失败；这排除了“该形状标签必然失败”的说法，但没有单独识别接触配置、观测历史或估计误差中的因果因素。

**硬安全反例必须保留：** `c_open_away_pos1_initial_location_hint` 的终点误差为 3.6293 米。已保存帧中的首次机器人中心入物体发生在 200.95 秒、BRAKE阶段；全记录最大穿透 0.4301 米，超过原预算 0.1825 米。原求解器没有fallback或infeasible记录，仍不能据此推导物理安全。见[离线时序核验](far_safety_failure.json)，生成入口 `scripts/audit_cargo_far_safety.py`。这是一项未解决的研究限制，不是已经修好的案例；没有放宽阈值或重跑到成功。

活动控制仍采用自身/一跳观测及原全队阶段监督器；已知工作空间边界、任务方向/距离及机器人资源。没有先验外形不等于没有假设，远场实验也不证明任意复杂环境的完整搜索保证。

本轮只有一个货物，传感量测带对象标识，机器人自身位置和邻居位置使用共同坐标系。未知对象数量、多物体数据关联、自定位误差和实机链路不在本轮证据范围。新增权限回归检查确认六个盲起点场景的首帧搜索命令不随未观测货物的位置或形状改变。

## C 背向的一个否定结果

大误差主要在初始化之后形成。本轮仅测试一次先拟合运动再裁剪创新的候选。同输入局部参考读数对照精确复现 2850 次；配对位移 MAE 从 0.642166 米变为 0.594161 米，降低 7.48%，终点估计误差仍为 0.715277 米。未通过冻结门槛，没有启动候选闭环矩阵或继续调参；该选项默认关闭，主比较也关闭。见[原始分析](reference_negative_analysis.json)和[带符号误差图](reference_negative_result.pdf)。

## 研究贡献与边界

系统贡献是具有明确信息权限的感知、地图、部署、接触推进、估计和停止流程，以及从真实轨迹得到的完整任务证据。边界 CVT 是待独立归因的部署模块；CVT、QP/CBF、ICP、PI 和搜索扫描等标准组成不能单独包装为新算法。当前结果不会通过增加容易形状、剔除失败或延长预算变成“90% 可靠”。

原完成规则仍为 HOLD、真实平移速度 <=0.005 m/s 持续40帧、二维终点误差 <=0.12米；没有新增角速度判据。硬安全采用原间距、穿透预算、求解器检查；G500单列。600秒观察截止不是成功耗时；全部启动任务进入分母。统计单位是条件配对，不是逐帧数据或匹配数。
