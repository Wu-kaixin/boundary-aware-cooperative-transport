# 边界部署的独立贡献：既有匹配回合审计

2026-11-03。这是一项事后机制审计，新增物理回合 0。完整使用先前冻结的
12 个初态条件 × 三个部署方法、共同 0.45 运动先验的 36 条轨迹；这些条件
已经用于开发，不能称为新的独立验证集。

逐块核验了配置、seed、机器人初态完全相同，原协议、源码快照和所有产品收据
哈希一致。代码干预仅在 CONTACT_READY 前替换部署目标点；感知/通信权限、
CVT 质量和重部署守卫、安全层、物理及接触后控制共同保留。实际地图会随策略
轨迹变化，因此“权限相同”不等于事后观测数组相同。

每块取三个方法最早 CONTACT_READY 的控制时刻为共同终点 T；在 `[0,T]`
的 20 个等间隔内，按独立 360 点物体边界和原 0.42 m 评价接触半径计算
覆盖率及最大未覆盖弧长上界，做时间平均。机器人路径则使用该共同前缀的所有帧。
T 是逐块共同的、由就绪事件确定的时间，不是跨场景统一时长。所有块和方法均保留。

| CVT 相对比较项 | spacing | nearest |
| --- | ---: | ---: |
| 时间平均覆盖率差 | +1.52 个百分点 | +4.85 个百分点 |
| 覆盖率占优 / 落后块数 | 10 / 2 | 12 / 0 |
| 时间平均最大未覆盖弧长减少 | 0.052 m | 0.190 m |
| 同时段每机器人平均路径差 | −0.129 m | −0.013 m |
| CONTACT_READY 时间差 | +1.01 s（较慢） | −0.33 s（较快） |

这些结果支持边界 CVT 在已观察条件下改善部署覆盖和空缺，尤其相对 nearest；
相对 spacing 的覆盖增量较小，且就绪时间存在取舍。这里没有把逐帧样本当作
独立重复，没有推断任意形状总体成功率，也没有声称统计显著。

完整任务结果沿用各回合原来的执行身份和判据：

| 指标 | CVT | spacing | nearest |
| --- | ---: | ---: | ---: |
| 完整任务完成 | 11/12 | 11/12 | 11/12 |
| G500 | 9/12 | 6/12 | 8/12 |
| 硬安全失败 | 0/12 | 0/12 | 0/12 |
| 全回合屏障缩放次数 | 5 | 123 | 26 |

屏障缩放次数来自各自完整运行时间，属于执行代价描述，不是共同时间前缀的
发生率。**部署覆盖贡献有证据，完整搬运完成率优势没有成立。**
远场错误停止仍是共同控制链的问题；不能把公共估计/安全修复归为 CVT 的贡献。
