## 旧C形为什么接近目标却不结束

完整12000帧重建与历史地图、局部反馈、共享监督器输入精确一致。末端真实位移为[1.184991, 0.018301]米，公共估计为[0.702140, 0.042038]米，估计目标误差为0.499632米。原始累计量已低估，1.24增益在末端缩小了低估；不是满足到达条件后丢失HOLD。

当前匹配“可信”只表示瞬时可辨识，不保证历史累计量准确。配准、融合及投票切换的记账可精确重建，但物体静止时仍积累了表观位移。见[带符号分解](signed_accounting.pdf)、[详细核验](historical_reconstruction.json)及[停止门控](stop_guard_audit.json)。

## 同输入估计改善，不等于闭环运输改善

在同一旧C轨迹的30–600秒窗口，平均共享位移误差由0.281922米降至0.011954米，末端误差0.014438米，可用率100%。这是一个历史轨迹的逐帧描述统计，不是11400个独立样本，也不是闭环成功。见[同输入图](estimation_comparison.pdf)和[预先门槛及结果](offline_gate.json)。
