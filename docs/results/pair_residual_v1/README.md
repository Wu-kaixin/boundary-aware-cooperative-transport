## C 形正式激活与非推手运动

当前配对候选在 CONTACT_READY 的 483 帧中，声明推手最多 **2 台**，正向物理接触首子步样本最多 **3 台**。BRAKE 从控制时间 **48.15 s** 开始；四台推手的阶段信号首次出现在 **49.50 s**，晚 **1.35 s**。制动前物体已位移约 **0.759 m**、旋转 **4.942°**，全程没有正式 TRANSPORT。该结论来自新候选本身的逐帧阶段重建。

CONTACT_READY 中可分解的非推手机器人步为 **5,363**，其中 **2,332** 步的名义指令沿当时真实法向向内，覆盖运动残差向内而返回的搬运/退让分量不向内；**2,328** 步的滤波后指令仍向内。655 个正向接触首子步样本中，191 个属于非推手；其中 117 个与上述向内名义指令相伴。详见 [分阶段分量表](c_components.csv)、[全部八回合阶段表](all_eight_phases.csv)和 [完整阶段/接触结果](phases.json)。

这里的覆盖分量是“实际送入滤波器的名义指令减去返回的搬运分量”，仅统计搬运函数被调用且名义指令未被后续覆盖的非推手。法向取控制前真实几何，接触样本取机器人完成当步位移后的第一个物理子步，二者时点不同。上述是关联证据，不能把全部接触力矩或最终转角因果归给覆盖项。全轨迹 7,536 个合格非推手样本的滤波指令与原保存位置差分一致，最大差异 `8.89e-15 m/s` 以下，见 [附加执行核验](command_realization.json)。

## 下一项研究决策与证据边界

保留现有可达性截断和阶段准入保护。直接允许上述两份截断后的配对，会把已经放松的物体需求包装成修复，不能满足原完整裕量目标。下一步优先追踪 989 帧参考聚合行的有限边界来源，以及 402 帧有限支持行的几何保守性；对后者还应单独评价是否需要超过两台机器人的局部协调。C 形则需把部署运动、可参与推手的邻域确认和正式施力条件对齐，先确认干预能形成原四台门槛，再冻结匹配物理试验。保持数值参数与门槛，不同时混入多个未经区分的干预。

此诊断不能证明任意未观测边界安全、异步通信或硬件时序，也不构成新物理效果、泛化或独立部署收益证据。公共搬运链稳定后，仍需未使用条件验证、CVT/spacing/nearest 匹配对照及 CCTA2027 论文更新。
