## 计算和证据边界

对原指令u、新有限支持法向n和几何余量h，未截断残差为
`r = n·u + gamma_obj*h - rho - demand_speed`。每个获准状态的全部物体行均核对
已保存的截断和未截断最小残差，再选择最小未截断残差行记录四个加性项。
负h的计数只指这条选定行：17个正向力状态中11个负h，11个推手状态中8个负h。

对任意满足 `||v||≤B` 的有符号运动，柯西—施瓦茨不等式给出
`r(v)≤n·u+gamma_obj*h-rho+B||n||`。每个见证使用原矩阵逐项核验，
并检查 `v=-B*n/||n||` 达到该单行上界。上界低于既有−1e-7容差时，该行排除原指令。
上界非负的其余状态只是不确定，**不代表完整联合约束可行或任务获救**。

四条件均保留原 `r_safe=0.065m`、`gamma_obj=8`、`rho=0.02`、
机器人限速0.35m/s和配置运动界0.2m/s。速度球是该模型的配置假设，
不是物体真实运动证书。这里也未将半间距、测量噪声和法向误差各自分离，
未重新求解控制器，更不能用同状态代数结果独自证明四条失败轨迹的完整因果链。
