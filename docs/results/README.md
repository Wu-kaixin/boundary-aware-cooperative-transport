## 使用规则

1. 从批次清单确定源码、环境、协议和成功定义，再引用数字。
2. 执行完成、接触就绪、物理接触、收定、G500 与任务完成是不同测量。
3. 保留执行异常、删失事件、任务失败和全部计划案例的分母。
4. 静态 oracle 结论、未知边界经验结果与动态接触搬运分别论述。
5. 生成新分析或重跑时写入新目录，不能覆盖历史收据或将旧数据标成新验证。
