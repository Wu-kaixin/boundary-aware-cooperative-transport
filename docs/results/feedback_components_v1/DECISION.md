# 研究判断：结束本轮反馈分量搜索，转向可恢复的有效接触

本轮问题是：上一轮 C 背向早期失去推进，主要由位置、速度还是反馈准入改变造成？共同准入的四臂比较已经执行完毕，没有追加种子、时间或调参。**四臂均未完成 C 背向，不能把原因归结为某一个速度通道，也不能宣称估计修复已经解决运输。**

## 可以成立的结果

本轮36个新回合中，共同准入＋旧通道、只换位置、只换速度、双通道依次完成3/9、6/9、4/9、6/9；G500依次2/9、2/9、1/9、3/9。原CVT、spacing、旧二维CVT的27个冻结历史参照分别完成5/9、5/9、5/9，G500为5/9、4/9、1/9。执行身份不同的结果没有伪装为同批新执行。

- **参考位置值得保留为实验选项。** 只换位置与双通道均保留原来的五个完成条件，并增加椭圆垂直方向。前者在342.20秒结束，后者483.85秒；终点误差分别45.76、44.78毫米。两者的24、25次屏障缩放使G500失败，不能称为全面改进。
- **没有证据要求同时换速度。** 在这一条件下，旧速度配合新位置已经完成；但只换位置的总G500比双通道少一例，其他条件的时间和误差也有取舍。两个版本各自的速度误差来自不同轨迹，不可当作同输入估计精度的胜负。
- **准入不能忽略。** 新准入配旧数值仅完成3/9，两个L形在约0.125米处收定，超出原0.12米容差；这不是原CVT。准入改变可能让原地图数值进入不同控制决策，不能把该臂自动称为“更可靠的旧方法”。
- **新的准入对照出现两例硬超限。** 椭圆平行方向最大穿透0.170612 m，超过该执行记录的0.097036 m预算，最小有符号间隙为−0.040612 m；椭圆垂直方向最大穿透0.101556 m，超过0.099001 m预算。其余三个新组合未记录到本轮所检查的间距、内侵、穿透预算或求解失败超限；这不等于G500或一般动态安全保证。两例不利结果保留，准入对照不推广。
- **速度单独替换有不利结果。** 它在椭圆垂直和C开口朝向分别以0.197、0.129米误差收定，仍按原规则判未完成。没有放宽容差去补齐完成数。
- 圆形、椭圆平行方向、C背向在全部四臂均未完成。600秒是观察上限，不是已经证明永远失败；本轮也没有继续追加观察来寻找成功。

## C背向的分量效应与限制

| 共同准入下的组合 | 终点误差 | 制动原因 |
|---|---:|---|
| 旧位置＋旧速度（00） | 0.405178 m | contact_recovery_failed |
| 新位置＋旧速度（10） | 0.721097 m | contact_recovery_failed |
| 旧位置＋新速度（01） | 0.345503 m | contact_recovery_failed |
| 新位置＋新速度（11） | 0.783854 m | contact_recovery_failed |

在旧位置下换速度，误差下降约59.7毫米；在新位置下换速度，误差增加约62.8毫米，误差尺度上的交互量约122.4毫米。新位置在两种速度下均增加该例的物理终点误差。**这些是闭环干预后的任务结果，不等于参考位置本身估计更差**：位置还改变推力方向、推手资格、阶段进入时刻与随后的接触轨迹。

控制器最后实际采用的二维位移估计误差，00、10、01、11分别约206.4、11.8、596.7、26.1毫米。10和11能较准确地知道物体仍未到达，却未能维持足够推进。这直接区分了“知道在哪里”和“能把它推过去”；各臂轨迹不同，仍不能把这四个误差当成同输入估计精度试验。

旧双通道日志已显示，在13.9秒暂停时仍有16个有效参考读出，却只有两个反向物理接触；17.9秒就因恢复超时进入BRAKE，距目标仍约1.07米。说明只检查最终一帧“到点没有”会遗漏早期接触配置变化。新四臂也都因接触恢复失败进入BRAKE，未救回C背向。

末10秒的描述审查补充了物理解释：物体质量4.1175 kg，冻结模型的静摩擦启动阈值约24.236 N。10、01、11三臂在200个控制开始时刻的合力均低于此值，随后物理步速度为零；00有14个时刻超过阈值，仍未到达。这与末段有效推力不足一致。该审查只使用评价真值，不给控制器增加力真值；它不是所有子步的力锥证明，也不说明增大压入量或降低摩擦就可安全解决。

## 已确认的工程问题，与尚未解决的研究问题分开

现有暂停逻辑禁止所有实际推手标志，而恢复门控又用这些标志累计正的推手人数，形成循环依赖。源码与12,000帧全队谓词的核验支持这一实现问题。它是在本轮冻结后发现的，因此没有混入任何一臂。

但是，去掉暂停条件后计算的影子资格在原80个暂停帧中也从未达到4个推手。修复计数可达性是必要的工程工作，**还没有证据表明它足以救回此C形**。影子几何资格也不是实际接触确认，不能直接替换成“已安全接管”。

应研究的具体问题因此收敛为：**在局部观测下，怎样区分“允许尝试接触”“确有有效推进”和“退出原推手后仍能维持推进”，并允许暂停后恢复这一过程？** 当前证据支持研究这个问题，不支持宣称已经找到了保证完成的策略。

## 下一步及停止条件（尚未执行）

1. 先单独修复恢复计数对执行开关的循环依赖，用构造输入验证暂停、重新具备资格、持续确认、恢复、超时和估计缺失的分支。原人数、持续时间、安全门控及终止标准保持；“资格”和“接管确认”使用不同记录，不能把取消暂停当成接触成功。
2. 再冻结一套反馈，优先以本轮精确复现的双通道版本作开发参照；不能在接触实验中同时换位置/速度、QP、物理或成功定义。先比较原恢复逻辑与仅修复恢复逻辑，确认是否只是修复可达性而未改善接触。
3. 若仍不能形成有效推进，才加入一个有预算的局部重新接触/侧向换位方案：保留已有有效推手；替补只能由允许的局部观测和邻居消息提供持续接管证据；未确认时回退，不能全部同时退出。实际力和物体真值仍仅用于独立评价。若现有观测不能支持该确认，应报告信息缺口，不把几何接近伪称为实接触。
4. 下一阶段可限定为圆形、椭圆平行、C背向三个已有失败条件，每个最多600秒、一版不调参；先做两臂6回合的工程核验。接触候选是否增加第三臂，须由该核验决定并另行冻结，不能回写本轮36回合。这个安排尚未执行，不是已取得的能力证据。

本轮停止新增反馈候选，不做v3/v4式连续调参；参考位置与双通道保留为开发选项，默认累计反馈不替换。全部数据仍是同一个反复使用的开发seed，不能报告独立泛化成功率。论文标题及稿件未变，研究贡献仍需以真实任务能力、信息权限和保留的失败边界来界定。
