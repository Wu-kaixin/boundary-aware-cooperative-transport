## 本轮真正隔离什么

四种新执行组合共用“新参考读出有效才准入”的规则。00用旧地图位置和速度，10只替换位置，01只替换速度，11同时替换。00是**准入消融对照**，不是原CVT或旧二维CVT。缺失读出不伪造零值或静默退回旧值；CONTACT_READY前行为保持。

11的九个回合与上一轮候选的25个回放数组和所有历史逐帧字段精确一致：**True**。原CVT、spacing、旧二维CVT的历史输入及收据也重新核验，执行身份保留为历史，未标记为当前源码新运行。

## 从旧日志确认的接触与恢复问题

旧参考候选C背向在9.0秒进入TRANSPORT，13.9秒暂停，17.9秒因接触恢复超时进入BRAKE。当时还离目标约1.07米，有16个参考读出；不是缺估计或已到达。13.9秒两个实际接触都反向，而7个机器人仍报告几何contact-ready。原二维方法直到32.8秒才进入TRANSPORT。

暂停禁止所有`push_side`，恢复时钟却依赖这些实际推手标志；该路径存在无法自行恢复的循环依赖。全部12000帧、每帧所有机器人的推手谓词重建零差异，80暂停帧的标志和计数均为零。但去掉全局暂停后的影子资格也没有达到4推手门槛，不能据此保证修改计数即可救回该例。它仍不等于实际接触确认。见[恢复逻辑核验](recovery_loop_summary.json)。

新四臂C背向的末段力审查是事后限定的最后10秒描述，不是新成功判据。物体质量4.1175 kg、地面摩擦系数0.6，模型静摩擦启动阈值约24.236 N。位置、速度和双通道三臂的200个控制开始时刻，接触合力范数都低于此值，随后物理步的速度均为零；共同准入旧通道臂有14个时刻超过该值，仍未到达。该结果与末段推力不足一致，但不是所有物理子步的力可达性证明，也不说明改大压入量就会安全成功。详见[原始日志派生力审查](c_final_force_audit.json)。

这个问题在批次冻结后发现，未混入本轮运行源码；其修复需要独立身份。没有通过放宽门槛、延长时间或更换seed获得结果。所有新开关仍为实验选项，默认保持旧累计反馈。
