# 有限支持与推动接触的兼容性诊断

诊断完成时，独立八回合物理批次仍在运行；本报告新增物理回合 **0**。
四个已完成对照分别精确复现旧桥接轨迹。本次只读重放核验 **1749帧**，
在预先选定的8个接触时刻保存全队 **128个机器人状态**。

关键发现：这8个时刻中，**17个实际产生正向接触力的状态全部违反新物体约束**，
无论是否使用需求截断；同状态重新过滤后，13个机器人速度的目标向分量变负。
其中11个既被声明为推手、又实际产生正向力的状态，新速度的目标向分量全部变负。
这些是机器人速度的反事实结果，不能直接称作反向物体力或新的闭环失败。

## 完整选择与分母

每个对照都选初始参考冻结后、BRAKE/HOLD之前的两项事件：首次正向物理接触力，
以及正向接触力总和最大的一步（并列取最早）。选择不使用新约束是否可行。
每个事件均分析全部16台机器人，另单列全部实际正向力贡献者，无删选失败项。

## 验证与限制

重放逐帧比较原命令、完整诊断、求解统计、阶段/守卫/响应和地图点。
新过滤器使用独立实例、同一原名义速度、参数与地图运动输入，以及当前本机/一跳扫描。
全部原邻机硬约束逐行保持。原控制器、物理指令和八回合运行均未改变。
物理接触力只在原指令固定后用于评估分类，未输入反事实控制器。

原始矩阵、命令和每帧状态在
`runs/research/2026-11-03-post-support-contact-compatibility-v2/`。
[来源](provenance.json)绑定原控制收据、运行源码、设计、脚本和原始分析哈希；
[发布清单](publication.json)核验公开产品。v1的首个对照重放后因数组序列化失败退出，
原失败、脚本及设计快照保留；v2只修正结果输出转换，没有重跑物理。

## 对下一步的影响

此前17个远场缩放状态的可行性恢复没有检查推动能力保持。本诊断表明，
把运输阶段所有获准物体行一概换成当前有限支持行，会排斥原本有效的接触指令。
因此，下一机制必须同时解释“如何修复有限边界之外的错误排斥”与“如何保留合法推动接触”，
并在相同参数与完整闭环门槛下验证，不能仅以QP可行或缩放减少为成功。
当前物理批次必须按原预算完成；其真实任务结果和约束审计仍是后续决策依据。
