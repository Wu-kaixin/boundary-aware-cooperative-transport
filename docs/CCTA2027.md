## Project decisions

CCTA includes robotics and control implementation. We organize around a reproducible control
application: local observations, deployment targets, hard safety filtering, physical contact
and independent evaluation. A six-page main-text target is our editing choice. The conference
does not require this Python directory layout or our tests.

The [manuscript map](../manuscript/ccta2027/README.md) links sections to implementation.
Current evidence limits the scope:

- Static theory uses explicit assumptions and oracle geometry where stated. It does not
  establish unknown-map dynamic-contact safety.
- Segment/gap guards are empirical candidates. A truncated observation-gap quantity is not
  a proved geometry error bound, even if an offline path check is safe.
- Readiness gains against nearest targets must be reported alongside local spacing,
  physical readiness, censoring and task outcomes. General transport advantage does not follow.
- `push_cone` existed locally before this refactor and remains exploratory. Its unit test
  does not make it a supported contribution.

Use the [claim–evidence matrix](paper_claim_evidence_matrix.md) for numerical claims. Its October 7
tables refer to archived source snapshots; moving code does not regenerate them. Changes to
algorithms, protocols or evaluation definitions require a separately identified study.

## Reproduction readiness

1. Install the simulation/solver environment and run unit and architecture checks.
2. Run the smoke protocol in a fresh directory; inspect all five receipts and process status.
3. Freeze a new full study with sources, methods, seeds, horizons and metrics before execution.
4. Keep failed and censored episodes; separate development, diagnostic and test populations.
5. Build tables from recorded episodes and verify paired initial-state/task equality.
6. Review every paper claim against its population, assumptions and artifact provenance.

The refactor supplies the framework and smoke checks. Full scientific revalidation and an
authored manuscript remain research work; passing unit tests does not complete them.
