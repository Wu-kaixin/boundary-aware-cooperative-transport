# Phase 2：射线方向误差候选的固定状态评估

2026-11-04（Asia/Tokyo）。**停止把这个单一候选作为充分修复推进，不启动物理比较。** 它正确收紧了部分测距误差的方向投影，也增加了部分状态的方向能力数值，但没有消除任何预定的反向/不可行分类。此结论不否定全部 R1，更不证明新闭环必然失败。

本轮依据[上一轮模型审查](PHASE2_R1_MODEL_FEASIBILITY_2026-11-04.md)继续一个已具体提出的小阶段：保持原信息、噪声、物理、结构余量与判据，设计一个最小候选并作一次固定规格离线比较。新增物理回合 **0**，控制重放 **0**，运行控制器未改。原长期目标尚未完成。

## 1. 问题、候选与可证伪预期

科学问题是：原有限支持把测距误差当作各向同性距离扣减，是否因此丧失了推动所需的目标方向速度能力？仅利用已有射线方向，能否充分消除已保存的这些障碍？

[预先保存的设计](../experiments/ccta2027/phase2_r1_ray_direction_v1_design.md)固定了唯一候选、数据组和否证条件。此前结果均已见过，所以这是开发诊断，不是事后包装的预注册或独立验证。

| 项目 | 原有限支持 | 本轮唯一候选 |
| --- | --- | --- |
| 包、时间、来源、物体关联、准入与保留行 | 原规则 | 全部保留，不跨包连线，不新增支持 |
| 法向、半弦长/孤立点半间距 | 原值 | 原值 |
| 噪声幅度 | 每个特征 `ε=3σ=30 mm` | 原幅度，按原始射线方向投影 |
| 运动需求、γ、ρ、速度球、其他约束、cap | 原值 | 原值 |
| QP 目标与实际命令 | 原保存结果 | 未改目标、未执行新命令；只算方向能力 |
| 真值 | 仿真评价标签 | 仅离线评价，不构造候选 |

它与已有三射线直线拟合不同：不以拟合残差替换半间距，不丢特征，不更改噪声大小。和上一轮“只改运动项”也不同：运动需求完全未动。

充分修复的预定检验是：17 个原正向施力状态及四个预选推手的已知反向/不可行障碍是否全部消失。任一剩余障碍或数值不确定即否定充分性；只改善一部分需如实保留，不能算通过。cap 与未截断系统分别报告；cap 结果不承担严格安全证明。

## 2. 数学机制及预测

对每个原点/弦段，设端点为 `z_k`，其扫描源为 `o`，原距离梯度单位法向为 `n`。源位姿准确、量程为正时，原噪声沿 `d_k=(z_k−o)/||z_k−o||`。仅对假设的端点误差事件 `|t_k|≤ε`，定义

`K = conv ⋃_k { z_k+t_k d_k : |t_k|≤ε }`。

线性函数在该凸包的支撑值为 `σ_K(n)=max_k(n·z_k+ε|n·d_k|)`。因此使用

`L_new=n·p−σ_K(n)−structural`，`h_new=L_new−r_safe`。

原距离法向满足 `n·p−max_k(n·z_k)=dist(p,F)`。逐行核验后，有

`0 ≤ h_new−h_old ≤ ε`。

这是既定误差集合的标准支撑计算；`L_new` 是定向支撑平面间隙，不是到整个不确定集合的精确距离。不能只在原足点扣投影误差，必须对完整端点集合取最坏值。此处也没有原始边界覆盖、Gaussian 尾部、旋转运动界或分步安全的新保证。

保持 `A` 不变，未截断 RHS 降幅为 `γ(h_new−h_old)`。原 cap 在固定法向下是逐行取最小值，其 RHS 降幅在零与该值之间。因此原可行域包含于新可行域，方向能力不应降低。这是数学/数值一致性检查，不能当成科研成功指标。

有一个事前可检验的量级预测：当查询机器人就是扫描源时，单点和端点投影的增益均为零；相邻 72 射线的内部投影满足

`Δh ≤ ε[1−cos(π/72)] = 0.0285534 mm`。

对应原 `γ=8/s`，未截断 RHS 最大下降仅约 `0.000228427 m/s`。邻居特征不受这个自身原点角度界约束，最大可改善 30 mm。独立反方在结果计算前确认了这个推导，同时指出约束几何可能放大小距离变化，故仍须评估所有行，不能只用量级推断任务能力。

## 3. 固定数据与完整比较

继续使用原对照 128 状态（112 准入）和失败候选 64 状态（57 准入），无重选。17 个正向力状态是前一组子集，四个预选推手是后一组子集；它们不构成新增独立实验。正向力标签属于原命令之后保存的物理区间，不转移给反事实速度。

对照组表格中的“原”指此前已经保存的有限支持反事实系统，并非原实际执行的聚合控制器；本轮是在同一状态上比较两种有限支持构造，不能把这些分类重新贴到原成功轨迹上。

控制组 16 个未准入状态保留原原因；候选组 7 个未准入状态保留原系统及命令，单独记为不变回退。下面只统计可构造候选的准入状态。每格为 **正向能力 / 必须反向 / 不可行**，前后数目与逐状态分类都相同，不是正负抵消后的净数：

| 固定组 | 准入状态 | 原 capped → 新 capped | 原未截断 → 新未截断 |
| --- | ---: | --- | --- |
| 原对照全部 | 112 / 128 | 99 / 11 / 2 → 99 / 11 / 2 | 99 / 9 / 4 → 99 / 9 / 4 |
| 原正向力子集 | 17 / 17 | 6 / 10 / 1 → 6 / 10 / 1 | 6 / 8 / 3 → 6 / 8 / 3 |
| 候选全部 | 57 / 64 | 55 / 1 / 1 → 55 / 1 / 1 | 55 / 1 / 1 → 55 / 1 / 1 |
| 候选预选推手子集 | 4 / 4 | 3 / 1 / 0 → 3 / 1 / 0 | 3 / 1 / 0 → 3 / 1 / 0 |

所有结果均有数值证书，无未决分类。候选未通过两种系统下的充分修复条件。

四名预选推手的目标方向最大速度如下，两种系统的新旧值在 `1e−14 m/s` 量级内相同：

| 原条件、帧、机器人 | 原最大速度 m/s | 新最大速度 m/s |
| --- | ---: | ---: |
| 圆形，110，agent_11 | 0.180236 | 0.180236 |
| L 形，96，agent_12 | 0.147163 | 0.147163 |

斜箱的负上界直接说明该状态仍无非反向可行速度。前三例的方向支撑值不变，却不证明另一种 QP 目标的最优命令也不变；本轮没有计算或执行这种新命令。

## 4. 正面结果、失败与未解决项

不能把分类不变写成“没有数值改善”：原正向力子集中，有限最优值配对的最大方向能力增量为 capped **0.071199 m/s**、未截断 **0.073908 m/s**。这是最大值，不是平均收益，更不是物体实际速度。候选组对应最大增量为 **0.062183 m/s**。它们均未跨越能力分类。

控制组自身 1,971 行的最大距离增益为 **0.025041 mm**，邻居 1,842 行为 **29.990684 mm**；候选组自身 989 行为 **0.026990 mm**，邻居 976 行为 **29.969295 mm**。所有自身行满足事前角度界。候选确实利用了方向结构，而非把噪声幅度改小，但主要已知障碍并没有因此消失。

112 个真值标注准入对照状态中，最小新下界高于真实距离的状态仍为 0；真实距离满足原下限、模型却为负裕量的状态仍为 **20/112**，正向力子集仍为 **11/17**。这组有限观察不认证任意未知边界。

原正向力状态的保存命令在新旧物体约束下仍全部违规，capped 与未截断均为 **17/17**；这里“违规”是相对于反事实新物体行，不是 17 次碰撞或物理失败。全部控制状态的保存命令违反 capped 行数从 29 降至 27，未截断从 30 降至 28；这些局部改善保留，未被丢弃。

上一轮隐藏凸起反例、无界 Gaussian 噪声、初始代理负裕量、分步执行与边界运动界缺口仍然存在。readiness-v1、progress-local-v2、anchored 的否定结果及原有限支持候选 0/4 完成保持原结论。本轮没有扩大形状、朝向或目标方向矩阵。

## 5. 验证、执行故障与文件保护

全部 **5,778 行**由独立标量路径枚举 **23,112 个端点误差顶点**复核支撑值，并核验端点来自原包、物体关联、结构和噪声幅度、原法向及准入原因。新旧四种系统共 **676 套方向证书**经另一标量路径检查。最大支撑值差 `1.78e−15 m`，最大原始—对偶间隙 `1.66e−8 m/s`，最小可行行残差 `−5.55e−17 m/s`。它们是重复状态上的数值验证，不能当成独立实验样本或严格浮点形式证明。

## 6. 对论文贡献和下一步的裁定

本轮保留了一个正确的“既定径向误差集合支撑计算”组件及一个否定机制假说的结果，未产生新搬运成功证据。不能把标准支撑函数运算或鲁棒屏障一般思想作为原创控制理论。已有测量鲁棒 CBF 已明确研究测量不确定性与安全控制的关系，本项目需要的是特定信息限制下对完整任务的新贡献，而非重新命名该框架。[Dean et al., CoRL 2020 / PMLR 2021](https://proceedings.mlr.press/v155/dean21a.html)

本轮有限检索使用三个问题：“LiDAR anisotropic uncertainty ray direction control barrier function robotics paper”；“robust control barrier functions measurement uncertainty support function polytope paper”；“LiDAR radial uncertainty covariance paper robotics”。核对了上述 PMLR 原文，未完成系统新颖性检索；Stanford 凸优化书网页/PDF获取超时，未据此新增文献断言。候选公式以本文直接推导为依据，未声称检索不到就代表新颖。

**建议停止本单一候选作为近期修复，保留其数学组件，不再沿它调参数。** R1 的经验距离修补尚未成为可部署主线；R2 仍只能处理可行域内的选择，不能消除本轮保留下来的空集或强制反向状态。不得为了延续主线而自动启动第二种几何规则或物理回合。

下一阶段更值得先明确研究主张，而不是继续调余量。推荐审议**显式局部几何条件下的 R1 模型**：完整形状仍未知，但明确哪些局部正则性/可见性条件能够约束未采样边界；噪声仍保持原模型，严格结论只能条件于真实成立的误差事件，所有条件违反仍完整报告。局部假设不等于完整几何模型，但也是先验结构知识，必须在题目、主张和实验中诚实披露。

这涉及研究定义，需要用户确认。本轮没有引入曲率界、最小特征尺度、噪声截断或新的风险/成功阈值。建议下一预算为 **最多 1 小时离线、0 物理回合、0 控制重放**，仅交付最小假设、与圆/椭圆/矩形/L/C 等形状的兼容性及一个明确否证标准，不直接接入算法。若用户要求完全保留当前的形状假设，则应停止 R1 的确定性保证主张，转向明确承认保证边界的经验任务机制，重新选择科学问题；不能自行把这两条路线混为同一贡献。
