## G500 到底是什么

G500 是本项目历史命名的**闭环验收合同**，不是通用文献指标，也不是一个部署算法。名称来自早期500帧预算；本轮沿用的四个阶段帧截止参数都是 `None`，单回合观察上限为600秒。因此不能把本轮 G500 解释成“500帧内成功率”。实际定义由 [ClosedLoopContract](../src/dbact/contracts.py) 和每个 `summary.json` 中的 `gates` 决定。

| 当前必须满足的条目 | 实际口径 |
| --- | --- |
| 检测、CONTACT_READY、TRANSPORT、到达事件 | 都必须有记录；取消阶段截止不等于允许事件缺失 |
| 目标方向进度 | 沿任务方向投影的终点误差不超过0.12米 |
| 边界覆盖 | 回合内严格覆盖率峰值至少0.70；不等于 formal caging |
| 结束 | 进入 HOLD，终速不超过0.02米/秒 |
| 求解与物理 | 不得使用脚本驱动物体；QP fallback/infeasible为零 |
| 约束缩放 | `barrier_scalings == 0`；缩放指原约束不可同时满足时降低物体约束要求，发生缩放不必然等于真实碰撞 |
| 硬安全 | 机器人最小间距满足原阈值及原数值容差、中心未进入货物、最大压入量不超过原离散预算 |

效率、方向误差、横向偏离和旋转另记为质量信息；其中已规定的缺失数据检查仍保留，不能把已有质量警告错误说成全部硬门槛。

任务完成另按**二维目标误差≤0.12米、HOLD、物理速度≤0.005米/秒连续40帧（2秒）**判断。最终报告还将其与硬安全取交集，称为安全完成。G500包含更多过程要求，但到达项只看方向投影，因此不能用它替代二维任务完成，也不能说两者天然是严格包含关系。

例如，旧矩形平行条件终点误差约0.02168米，任务完成，却从 CONTACT_READY 直接进入 BRAKE，未记录 TRANSPORT，故G500失败。该事件代表公共阶段激活条件未满足，不等于没有物理推进。不能补写事件或降低 quorum 来制造通过。旧近场C背向与U托盘则同时有真实终点偏差，必须解决控制/估计问题。

## 本轮诊断与参数依据

原近场CVT安全完成31/33、G500为27/33；远场未知位置6/6检测、3/6安全完成，并不代表远场可靠运输已经解决。位置提示组另有1例硬安全失败，全部保留。

离线读取旧日志发现：C背向、U托盘和远场斜箱存在错误停稳及显著位移估计偏差；C背向、U和斜箱的速度分别有84、21、12个保存帧超过估计器0.25米/秒的运动先验。这些帧不是独立试验，也不能仅凭同时出现就把运动先验判为根因。远场C的极端2米/秒峰值伴随严重后期物理失效，不能用它为正常估计器设定速度。

| 设置 | 唯一改动 | 可检验解释与风险 |
| --- | --- | --- |
| reference | 原共同修复版本 | 新执行重放应与冻结原例科学记录一致 |
| slower_reference | 运输参考速度0.055→0.035米/秒 | 较缓推进能否减少估计与停止误差；也可能降低有效推力、延长暴露时间 |
| lower_effort | 法向压入速度上限0.30→0.18米/秒 | 限制执行努力能否降低约束冲突；这是速度命令上限，不是牛顿单位的力上限 |
| slower_deployment | 边界接近比例增益`kp_cage` 0.9→0.6 | 能否减少部署过冲/密集接触；也可能延迟部署，改变后续接触布局。此增益也作用于运输期边界保持，不是只改CONTACT_READY之前的纯部署消融 |
| tighter_registration | 配准关联距离0.12→0.08米 | 收紧局部匹配是否减少误配；也可能增加拒绝和失去反馈 |
| wider_motion_prior | 地图/参考跟踪运动上界0.25→0.45米/秒 | 能否减少合法运动被拒；也可能接受错误匹配。物理速度上限和安全过滤器的速度界不变 |

八个筛选条件：近场圆、椭圆平行、矩形平行、C背向、U托盘s0/r90、T载荷s0/r90；远场斜箱pos0未知位置、C背向pos1初始位置提示。六组各8回合，seed2、相同初态、物理、传感、资源、600秒上限和成功安全定义。

入选候选必须无执行异常、无硬安全失败，并满足安全完成数至少增加1且G500不下降，或安全完成数不变而G500至少增加2。入选后按安全完成数、G500、平均终点误差依次选择；完全相同则按事先设置顺序。全部参数表及选择规则先于结果冻结。没有入选者则止于48回合。

最多只对一个入选设置追加24回合：椭圆垂直、斜箱s1/r90、远场C背向pos0未知位置、远场斜箱pos1未知位置；原/入选设置×CVT/spacing/nearest。这些是其他已知开发条件上的迁移检查，不是独立保留集。任何完成下降、新增硬安全失败或总体任务/G500均无提升，均不将该设置采纳为全局默认。不存在在各条件选不同参数再拼成“成功率”的做法。

## 已确认的工程修复

`contact_patch_distance`原先从仅在`trace_enabled`时更新的`last_scans`读取观测。关闭诊断会让控制器退回地图距离，改变控制信息。本轮将新鲜自身扫描的保存与诊断开关解耦，并在无传感帧保存空扫描。新增测试先复现缺陷，再比较日志开/关时收到的观测和实际命令轨迹。旧研究运行均开着日志，因此这项修复不能解释旧失败，更不能把改善归给它。

## 更能说明贡献的后续对照

一次只使用旧轨迹的离线分解进一步区分了**配准误差**和**所跟踪参考点与任务质心不同**。设机器人在初始化时刻τ跟踪的局部材料参考点相对真实质心的杆臂为ℓ，初始化位移偏差为b。即使后续刚体配准完全准确，其相对任务质心的位移误差仍可含有：

`e_reference(k) = b + (R(theta_k - theta_tau) - I) * ell`。

机器人自己的读出误差可分成上述两项与实际配准残差；这只是运动学记账，不能从恒等式推出估计准确。团队采用分量中位数，故团队分解用“实际中位数减理想参考点中位数”定义残差，不能相加各分量的中位数或模长。

| 旧案例、终止前最后可用控制读出 | 实际团队位移误差 | 同参考点、同投票集合下理想配准的误差 |
| --- | ---: | ---: |
| 圆 | 0.0282 m | 0.0305 m |
| 椭圆平行 | 0.0086 m | 0.0087 m |
| 近场C背向 | 0.8249 m | 0.0264 m |
| U托盘s0/r90 | 0.2154 m | 0.1067 m |
| 远场斜箱pos0未知位置 | 0.4269 m | 0.0169 m |
| 远场C背向pos1位置提示 | 2.4026 m | 1.0769 m |

更关键的是，远场C在首次保存到机器人中心进入货物之前、200.90秒控制时刻，实际误差0.57868米，理想参考点误差0.57951米，两种团队读出的差只有0.00344米。此时并非提高配准数值精度就能消除约0.58米的任务位移误差；参考点/质心语义及初始化偏差必须一起处理。该例初始化杆臂中位数约0.970米、初始化偏差模长中位数约0.092米。近场C则主要仍是配准残差。**不同失败不能归结为同一个增益参数。**

这项分析仅重建了原始初始化扫描并使用已保存的接受读出；团队聚合与日志校核、带符号分解均通过。真值只进入离线评价，没有实现“理想配准控制器”，也没有运行其物理轨迹，所以表格不是候选性能或干预因果结论。[生成入口](../scripts/audit_reference_point_error.py)；完整结果在本地 `artifacts/research/2026-11-02-transport-tuning-v1/reference_point_audit.json`。

| 问题 | 最小公平比较 | 能支持的贡献与边界 |
| --- | --- | --- |
| 边界表示是否优于检测机器人位置表示 | 完整共同流程内CVT/spacing/nearest；另做边界支撑与检测支撑的表示消融，匹配核质量、感知和调参预算 | 区分边界信息的作用与CVT优化本身；现有检测支撑消融不是文献完整复现 |
| 是否只是依赖观测点稠密区 | 固定几何和初态，预先设置均匀/非均匀扫描或局部遮挡；比较弧长加权与未加权密度 | 检验对采样偏置的抵抗，兼报覆盖间隙、安全完成和额外观测成本 |
| 方向偏置是否真正服务于搬运 | 相同未知外形、共用后续控制，打开/关闭任务方向偏置；记录部署后有效推手和完成 | 将分布变好与可执行搬运连接；不把峰值覆盖当因果证据 |
| 改善来自估计还是接触控制 | 同输入离线误差评估，加固定预算的反馈通道诊断；已完成的oracle与失败候选继续保留 | 估计准确性与闭环反馈作用分开；oracle不得作为可部署竞争方法 |
| 能力能否迁移 | 参数冻结后，用未用于开发的初态、几何参数和远场位置分别验证 | 未见初态、同族新几何、未见形状族分别对应不同主张；不把一类推广为任意形状 |

最接近的工作要求具体对照信息权限：

- Song、Bai、Wakamiya的原文式(5)–(10)已经结合检测位置密度、CVT和机器人间CBF，且讨论未知位置与多货物分配。因此“CVT+CBF+未知货物”本身不能作为新颖性。可检验差异是测得边界及法向的使用、接触物理下的位移/停止及非凸失败边界；当前检测密度替换实验不能替代其完整策略。见[原文](https://arxiv.org/html/2602.19070v2)。
- *Collective transport via sequential caging* 已有未知外形的顺序部署、搬运和实机证据；其问题定义需要初始质心估计，运输中根据机器人位置估计质心。可对照初始位置权限、部署资源与终点估计，不可声称未知形状搬运首次出现。见[原文§3–4](https://arxiv.org/pdf/2106.03132)。
- Tang等的RSS2024工作明确研究接触模式切换、重规划和NMPC，使用已知物体内参及集中感知。它适合作为接触纠偏与规划能力的强参照；若引入本项目比较，必须标为不同信息权限组，不能把其全状态规划器和本地观测控制器直接混排成同等基线。见[原文§II、III、V](https://arxiv.org/html/2405.07908v2)。

目前稳妥的论文定位仍是：**具有明确信息权限的边界感知协同搬运控制系统，以及从未知外形/未知位置发现、边界部署、物理推进到停止的可追溯任务证据。**算法层面的优势需由共同控制流程下的公平比较单独成立。31/33是固定开发条件上的计数；它不证明任意形状的90%以上成功概率。
