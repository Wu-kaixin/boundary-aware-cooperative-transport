## 2. 新核实的执行链限制

前一报告给出的局部 Hausdorff 界不是直接替换一个几何函数就可传播到
最终命令的保证。当前代码有以下明确分支：

| 位置 | 已执行的源码核查 | 对未来认证解释的影响 |
| --- | --- | --- |
| `control/post_support.py:4` | 参考未冻结、当前地图运动不可用或缺少当前自身回波时返回空输入 | 未准入不能解释为新几何证书成立 |
| `safety/filter.py:991`、`:1049` | 先构造原地图聚合物体行；仅在 support.ready 时替换 | 几何检查未通过通常保留原聚合路径，不代表自动停止 |
| `safety/post_support.py:24` | 行需求采用接收点速度范数与配置上界的较小值；文件明确标为经验模型 | 局部几何认证不能补足真实物体运动误差界 |
| `safety/filter.py:1052` | 新物体行先经过 `_cap_to_reachable` | 后续可行性不保证未截断理论行满足 |
| `safety/filter.py:1080` | `b_original` 在截断之后保存、在可选零输入裕量夹紧之前保存 | 名称 original 指夹紧前的系统，不是原始未截断几何需求 |
| `safety/filter.py:1248`、`:1265` | 依次尝试含裕量行、去裕量行；允许时再缩放物体行 | optimal / relaxed_margin / scaled_barrier 必须区分，不能统称同一证书 |
| `control/controller.py:764` | 非 theorem 模式不禁投影回退，且允许物体行缩放 | theorem 配置项的名字不能被移用为当前搬运的定理保证 |

源码位置均来自本轮直接读取；这是代码语义核查，没有运行这些分支、
新增事件计数或重放已保存状态。非准入时最终速度还取决于其他控制逻辑，
并不是所有非准入状态都会非零运动。

一个额外容易混淆的边界是“停止即安全”。在此前条件模板
`n·u >= D - gamma*h + rho` 中，若 h=0 且 D+rho>0，u=0 不满足该行。
所以零指令既不能被默认当作这一证书的可行输入，也不能从机器人停止
推出运动物体不会逼近。这个代数判断不是实际碰撞反例，更不是新停止算法。

未来若采用局部认证模型，至少需要分别保留：几何前提证明、全保持段运动
与时序假设、未放松原行及最终命令残差。若这些条件缺失，局部几何证明
仍有条件性价值，但最终执行不得被标为同等安全认证。这里登记的是设计
必须解决的问题，本轮没有新增字段或改变现有安全/成功定义。
