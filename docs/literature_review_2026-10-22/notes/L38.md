# L38 — Decentralized Algorithms for Multi-Robot Manipulation via Caging

Guilherme A. S. Pereira, Mario F. M. Campos, Vijay Kumar, IJRR 23(7–8):783–795 (2004). 13 PDF 页正文文字已通读；显示公式、原图待复核。

凸多边形物体、已知完整形状，邻居相对位姿、物体粗略朝向、共享目标和公共参考速度。无动力学模型；以机器人构型空间障碍形成含物体位姿的有界自由分支定义 object closure，和力闭合不同（pp. 1–4）。

局部交叠检查用于**已建立 closure 后的保持**，前提包括初始无冗余机器人与循环邻接结构；建立 closure 的一般分布式保证未解决。朝向区间、最接近点的虚拟点机器人处理旋转与有限尺寸，均为保守充分条件（pp. 4–6）。Enclose/MaintainClosure/GoToGoal 切换保持和群体平均运动分析；Filippov 切换边界分析明确未覆盖（pp. 7–9）。理论质点全向模型和实机类汽车运动学之间仍有接口。

3–4 台实机搬运三角箱/包围主动圆形机器人，机载全向相机；**通信服务于多目定位与物体位姿估计**，控制决策无需通信，不能笼统称整套系统零通信（pp. 10–12）。未精确控制物体终端位姿、无复杂外部障碍验证。

对项目：应区分 enclosure、caging、force closure、任务方向可操作性、实际搬运成功。仅闭环围住或保持间距不能支撑后几项。
