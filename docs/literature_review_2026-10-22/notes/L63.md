# L63 — Robust normal estimation for point clouds with sharp features

Bao Li, Ruwen Schnabel, Reinhard Klein, Zhiquan Cheng, Gang Dang, Shiyao Jin；Computers & Graphics 34:94–106 (2010), DOI 10.1016/j.cag.2010.01.004。13 PDF 页正文文字已读，显示公式/原图待复核。

无组织三维点云；先随机平面/稳健残差估噪声尺度，再用面积归一 KDE 选局部切平面、检测外点。噪声假设高斯，默认 200 随机候选与分位 20%；99% 清洁三点采样概率以无效点比例 ≤0.7 为条件，不是法向误差或安全概率（pp. 3–7）。

两步邻域可不同，最近点属于所选平面内点才采用；点云连接性增强外点检测。需要足够密且几何分支有足够支持，大邻域抗噪同时平滑小特征，稀疏时不稳定。输出法向无方向，MST 定向可能在尖角处不一致（pp. 8, 12–13）。

合成与实际扫描物体，附去噪应用及 RMS 统计；处理大点云耗时分钟，未验证机器人闭环、二维 RayCast 或全局逐点误差上界。高质量法向不能自动认证物体未观测区域、曲率或真实接触。

对项目：普通 PCA 遇拐角/混合平面/外点的机制应纳入可靠性分析；方向、邻域支持和拒绝条件比平均 RMS 更贴近单侧推力。更换估计器可改善实现，但独特任务能力仍需由就绪判据与验证建立。
