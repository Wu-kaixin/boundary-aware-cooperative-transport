# L23 — Risk-aware Safe Control for Decentralized Multi-agent Systems via Dynamic Responsibility Allocation

Yiwei Lyu, Wenhao Luo, John M. Dolan, arXiv:2305.13467v1 (2023). 8 PDF 页正文文字已通读；显示公式、原图待复核。

从成对 CBF 余量/CVaR 累积风险，为双方分配互补责任。无显式通信但**每个体可观测所有机器人当前位置、速度及已知噪声分布**，不是有限局部感知；邻居的邻居信息通过全状态可见获得（pp. 3–5）。

互补责任相加恢复中心约束的代数结论；有界输入可能不可行，需额外设计，不在该代数性质中自动解决。全时域概率陈述不能仅从逐时置信水平推导，需审查联合事件/采样时域条件（p. 5）。正文单积分器速度约束和车道并入双积分器加速度实验之间的相对阶实现细节待原式核对。

三车并入 50 随机初态仿真、六个体换位案例；换位含右手死锁启发式，因此性能不能全归于责任分配。无硬件、无搬运。对项目：责任动态化、风险/保守性分配已有工作，应与自身信息成本及递归可行性一起比较。
