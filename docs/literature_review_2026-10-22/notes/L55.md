# L55 — Multi-Agent Control Using Coverage Over Time-Varying Domains

Xiaotian Xu, Yancy Diaz-Mercado；arXiv:1909.05377v1 (2019)。10 PDF 页正文文字已读，显示公式/原图待复核。

已知凸运动域及其边界几乎处处速度、可微正密度、机器人初始在域内。Leibniz 边界通量补偿使集中式 TVD-C 的 CVT 误差指数收敛；不是未知运动对象的在线边界恢复。分散 TVD-D1 使用截断 Neumann 近似，只得到近似跟踪，不能套用集中式精确指数结论（pp. 2–4, 8–9）。

均匀密度凸多边形给出解析积分。信息包括邻居及其邻居、广播域信息，平均六邻居支持平均计算量论证，不是最坏情况常数界。100 单积分器仿真、十 Khepera IV 实机，Vicon 与 Matlab 工作站；移动缩放虚拟矩形绕过虚拟障碍。驱动映射、饱和、延迟造成残余误差；没有实体全保持段安全证明或接触搬运（pp. 5–10）。

对项目：运动域上的覆盖与集群形状操纵已存在；区别必须是实际可获取的局部物体观测、明确的信息缺失处理及操作就绪条件，不能仅声称支持时变边界。
