# L26 — A Distributed Coordination Model for Multi-Robot Box Pushing

Marin Lujak；源 PDF 未在正文明确显示发表元数据，待查正式出处。6 PDF 页正文文字已通读；显示公式和原图待复核。

上层虚拟结构 VS 统一规划物体轨迹，机器人接触位置预分配；下层以局部超声/相机障碍信息、全队交换和乘积目标函数逐步优化运动。偏差过大重新向 VS 请求轨迹（pp. 1–5）。有中央高层规划依赖，不能据标题判断完全分散式。

弹簧式虚拟作用力/离散点运动，而非真实刚体摩擦、转动和接触冲量。三机器人圆形箱体 128×128 像素 MATLAB 示例，忽略模型和控制不确定性（pp. 4–5）。凸且充分分离障碍有到达论述；凹形环境不保证到达，动态障碍的严谨处理列未来工作（p. 6）。

对项目：未知外部障碍不等于未知物体几何；安全到达需区分规划示例和经过证明/物理验证的能力。
