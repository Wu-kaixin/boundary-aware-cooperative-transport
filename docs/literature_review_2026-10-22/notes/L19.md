# L19 — Object Rearrangement Through Planar Pushing: A Theoretical Analysis and Validation

Chun-Yu Chai, Wen-Hsiao Peng, Shiao-Li Tsao, TRO 38(5):2703–2718 (2022), DOI 10.1109/TRO.2022.3153785. 17 PDF 页正文文字已通读；显示公式、原图待复核。

单推杆、准静态、无障碍平面重排。先收集少量已知推法及实际 SE(2) 位移效果，再选择/缩放产生目标位姿下降的推法。效果需正张成 R³，支持面均匀、可重复、推长与效果线性缩放；未噪声的步数上界依赖 cost-space cosine measure 和终点精度（pp. 3–7）。

**效果空间的方向覆盖**联系任务收敛，而不是仅接触点在几何边界上均布。等间距法向接触更易得到正张成集合，但旋转对称形状的纯法向推法转动能力弱，作者对部分物体仅评估平移（pp. 9–13）。大样本/噪声仿真不是随机鲁棒定理。

MIT、Omnipush 与 11 个日常物体数据分析，实机 3 代表物体×12 任务×5 重复；UR10+多相机 AprilTag，明确目标 7.5mm/5°，变形鱼玩具每任务前人工整形（pp. 8, 14–16）。无多机器人安全部署，不处理探索未知接触/非均匀支持面的在线辨识。

对项目：任务方向可操作度、动作效果质量与所需终点精度已有明确理论联系。若提任务有效部署，需要说明与此正张成/方向质量指标的差异；保持力矩余量不能只看机器人间距。
