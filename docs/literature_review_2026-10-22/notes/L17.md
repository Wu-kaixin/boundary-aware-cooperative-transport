# L17 — Force-Amplifying N-Robot Transport System (Force-ANTS) for Cooperative Planar Manipulation without Communication

Zijian Wang, Mac Schwager；Drive 为含 Journal Title/ToBeAssigned 的作者稿，不能据模板 2015 判断正式发表年。出版方已核实为 IJRR 35(13):1564–1586 (2016)，DOI 10.1177/0278364916667473，见 [版本核验](../version_verification.md)。24 PDF 页正文、附录文字已通读；显示公式、证明与原图待独立复核，出版版内容差异尚未逐项对照。

已附着机器人利用物体局部速度/加速度隐式协调，无显式运行通信、跟随者无全局定位；仅领导者知道轨迹。CB-ANTS 处理动摩擦、P-ANTS 处理惯性+粘性摩擦；需要已知动力学参数和机器人总数，未知参数自适应列为后续工作（pp. 3–6, 20）。零速初始化以随机试力讨论，硬件用公共 kickoff 命令代替。

局部量受旋转污染：CB-ANTS 要角速度/平移速度关系；P-ANTS 分析还用质心中心对称附着及几何惯量条件。质心对称布局对力一致和扰动有直接作用，因此“均匀分布自动改善操作”的论断需要检验，而非照搬（pp. 5, 8–14）。领导者可施加直接力矩；不能转为单边推手模型。

ODE：20 机器人搬 2kg 椅子、1000 机器人搬 273kg 钢琴；附着点预设、路径和领导者姿态控制预设。硬件四机器人经螺钉连接一自由度夹具，局部光流/测力/关节角；仅领导者用 OptiTrack/中央控制。自主、遥控和直接人类引导分别 80/80/20 次，P-ANTS 硬件未做（pp. 14–20）。

对项目：无通信与局部运动反馈搬运已有理论及大量硬件验证。差异应是无需预附着的安全配置和单边接触能力；力一致、搬运和终点精度必须分别报告。离散证明中变系数乘积趋零与指数率条件需复核原公式，当前不评价其正确性。
