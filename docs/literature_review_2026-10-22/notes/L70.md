# L70 — Target circumnavigation of mobile robots using range-only measurements

Jie Wang, Baoli Ma, Kai Yan；Automatica 159:111386 (2024), online 2023，DOI 10.1016/j.automatica.2023.111386。八 PDF 页正文文字已读；显示公式/原图待复核。

单非完整车、静止点目标，仅距离，不需车位置/朝向或显式距离导数。引入侧向虚拟点及动态输出反馈，避免极坐标零距离奇点；无障碍下闭环原点全局渐近稳定。线速度及其一二阶导数有界且不渐近消失，控制平滑有界。不能解释成未知运动目标定理（pp. 2–4）。

障碍版本**允许碰撞并检测碰撞后反向**；孤立固定圆形障碍、半径小于期望轨道、最小转弯半径条件。轨道与障碍相交时允许无限次接触而仍保持目标距离，不是避碰安全控制（pp. 5–6）。

全向底盘锁侧速模拟单车，UWB 目标锚点/车标签，六限位开关、STM32、0.1s 采样；移置目标后再收敛是实证，移动目标与多机器人无碰撞列为未来工作（pp. 7–8）。对项目：要按真实任务区分包围、碰撞容忍和安全接触，不把未知目标位置等同未知物体轮廓。
