# L71 — Target localization and enclosing control for networked mobile agents with bearing measurements

Liya Dou, Cheng Song, Xiaofan Wang, Lu Liu, Gang Feng；Automatica 118:109022 (2020), DOI 10.1016/j.automatica.2020.109022。12 PDF 页正文（pp. 1–11）文字已读，显示公式/原图待复核。

单积分器，仅目标方位角，但各本地坐标朝向与全局一致；通信交换邻居方位和期望间距，按目标绕行顺序维持强连通环。无绝对位置不代表无共同方向，也不覆盖未知物体轮廓/遮挡（pp. 2–4）。

旋转产生持续激励，投影估计相对目标位置；目标速度有已知界，给出与速度界相关的定位/半径/角间距最终误差，并需切向增益与期望半径条件。任意加大估计增益不保证更快，作者明确讨论高增益会变慢。若一个节点获知目标速度，扩展 observer 后得到精确渐近队形；式 (56) 的导数通信与切换图接口需要逐式复核（pp. 5–9）。

最终距离有正下界不等于整个暂态避免零距离奇点，Lemma 3.1 的名义误差有界推及耦合扰动路径需要重点复核，不直接宣称证明错误。五机器人两种目标轨迹仿真，无实机；非完整运动和碰撞避免明确列未来（pp. 10–11）。对项目：边部署边估计已有先例；观测充分性和全段实体安全要单独提出并验证。
