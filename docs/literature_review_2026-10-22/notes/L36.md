# L36 — Decentralized Ability-Aware Adaptive Control for Multi-Robot Collaborative Manipulation

Lei Yan, Theodoros Stouraitis, Sethu Vijayakumar, RA-L 6(2):2311–2318 (2021), DOI 10.1109/LRA.2021.3060379. 8 PDF 页正文和附录文字已通读；显示公式、原图待复核。

已固定抓取的冗余机械臂，知道抓取位置/物体速度/共同任务。利用任务椭球匹配加权力可操作椭球，通过零空间构型优化增加指定方向力能力。异质输入限制、自适应动力学模型与控制不足量参考修改，**饱和时向全队广播不足量**，正常运行无需通信（pp. 2–5）。

稳定跟踪针对修改后的可行参考，不能解释为原始任务不降级成功；需分别报告参考降级与跟踪误差。关节位置限制未处理，部分未知非线性由 RBF 表示；正式证明依赖其匹配假设（pp. 5, 8）。

三组组件消融，质量/摩擦变化与成员失效，三异质机器人模型：全部为数值/Simscape **物理仿真**，并非三台实体机器人实验（pp. 5–7）。

对项目：“任务方向力能力优化+异质输入限制”已有直接先例。潜在新能力必须涉及未知边界上可选接触的位置、局部可观测性与有限保持段安全等未组合验证的具体条件，不能凭组合名称认定创新。

额外核查：原始 pp.3–4 的作用椭球、固定抓点运动关系及参考不足量式(19)已可视复核；不能将零空间构型优化误写为沿未知物体重选接触点，也不能将跟踪修改参考写成原任务未降级成功。
