# L66 — Safety of Sampled-Data Systems with Control Barrier Functions via Approximate Discrete Time Models

Andrew J. Taylor, Victor D. Dorobantu, Ryan K. Cosner, Yisong Yue, Aaron D. Ames; arXiv:2203.11470v2, 13 June 2022. Full extracted text, PDF pp. 1–8 read including the complete Theorem 3 proof (pp. 4–5); original figures and proof independently verifying all premises pending.

**Task:** use consistent Runge–Kutta approximate maps to synthesize practically safe sampled systems. Admissible controller family, local Lipschitz dynamics, bounded controls on compact neighborhoods, uniform barrier properties and one-step consistency are required (pp. 2–4).

**Guarantee distinction (p. 3, Remark 3 and Definition 5):** invariance is defined at sample instants. Practical safety gives an invariant enlarged set C_h within any chosen neighborhood C plus R as h becomes sufficiently small. It explicitly differs from exact inter-sample invariance of the original safe set. Never cite this as an unconditional whole-hold no-collision result.

**Mechanism/evidence:** Theorem 3 transfers approximate barriers to practical safety; Theorems 4–5 preserve convexity for a block-integrator structure with appropriate RK order. Simulated single/double inverted pendulums across eleven sampling periods and hundreds/grids of starts; no contact or unknown-map experiment (pp. 5–6).

**DBACT use:** compare exact held-segment geometry certificates with practical sampled-state safety using the same tolerance interpretation. A stronger guarantee in a narrower static oracle setting is not superiority over this general nonlinear theory.
