# L34 — Cooperative Enclosing and Grasping of an Object by Decentralized Mobile Robots Using Local Observation

Yuichi Kobayashi, Shigeyuki Hosoe, International Journal of Social Robotics 4:19–32 (2012)，在线发表于 2011。14 PDF 页正文与附录文字已通读；显示公式、原图待复核。

两阶段：围住较慢移动的已知圆形目标；随后在静止凸物体表面调整已接触机器人的位置。局部邻居观测、无需通信、不知总数，但邻居顺序/数量与探测角满足特定条件；点机器人、无外部障碍（pp. 2–4）。抓取需要自身及两邻居接触法向，并假设每次运动后仍在表面；尖角以小曲线替代（p. 3）。

围捕有顺序保持、环形均布、开链转闭环分析（pp. 4–6）。抓取把力闭合化为法向凸包条件，并通过局部形状近似得到移动量；**只考虑二维平移，丢弃力矩行**，不代表完整平面力闭合（pp. 7–8）。六机器人椭圆/六边形各 20 次仿真，另有增减机器人；六边形顶点聚集的姿态抗扰不足为作者明确局限（pp. 9–10）。

3–4 台带全向相机的实机仅验证固定目标的围住；未知形状接触操作、阶段连接和避障仍属未来工作（pp. 11–13）。不能把硬件围住实验当作抓取/搬运实证。

对项目：局部边界近似→分布配置→局部可检查抓取条件的思想已有直接先例。可检验的差异应具体到受限单边推力、力矩、非凸边界、未接触到接触的安全转换，不能只声称“局部信息用于有操作价值的部署”。

额外核查：原始 pp.7–8 已可视读公式/图。式(4.17)拟合矩阵在相邻法向平行时奇异（行消元给 detA=−det[n_i,n_j]），说明直接求逆的前提需审计；未核其代码是否有退化处理。平移闭合条件与任务转矩/观测能力的区别见 [理论核查](../theory_scope_checks.md)。
