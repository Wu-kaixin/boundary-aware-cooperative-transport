# L11 — Coordinated Informative Path Planning for Multi-Robot Search in Open Fields

Kyungseo Kim, Jinwhan Kim, JIRS 111:65 (2025), DOI 10.1007/s10846-025-02270-z. 16 PDF 页正文文字已通读；显示公式、原图待复核。

已知搜索区域，未知地标数目和位置，有限距离方位传感器。成功条件同时要求区域扫描和地标估计协方差达标。加权 Voronoi 分区、区内 TSP 扫描、FIM 几何优化、EKF 不确定度预测和拍卖分配探索/利用角色（pp. 3–8）。多种角色改变可观测性并非项目可直接主张的新概念。

100 次 Monte Carlo，以 3 机器人、4 地标、700×700m 区域和 50m 感知范围比较规划时间、执行时间、估计精度（pp. 9–14）。基线包括 MTSP、遗传算法、几种往返扫描；训练和优化计算成本不同，须注明条件。每区 TSP 与候选团队枚举仍限制规模，不能把空间分区等同于整体线性复杂度。

开放场地仿真，没有未知障碍的完整连续安全证明或硬件验证。对项目的价值是将“部署质量”落实为下游可测量能力，而非仅报告覆盖代价。
