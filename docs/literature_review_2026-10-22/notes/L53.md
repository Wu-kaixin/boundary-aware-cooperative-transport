# L53 — Monitoring Environmental Boundaries with a Robotic Sensor Network

Sara Susca, Sonia Martínez, Francesco Bullo；Drive 九页作者稿，正式文献 TCST 16(2):288–296 (2008) 的版本对应尚待核。九 PDF 页正文文字已读，显示公式/原图待复核。

已有初始边界估计，机器人初始已在边界上且有循环顺序；局部切向/曲率可估、可靠环通信及顺序更新同步。光滑单连通边界、弧长上下界、慢变化。每机器人缓存已访问弧及插值多边形；原算法存全体插值点，作者讨论可缩到前后段（pp. 1–4）。

插值点按曲率加权伪距离均匀分配，机器人按弧长均匀追逐；“最优”是大样本下局部凸弧多边形逼近，不是接触任务能力最优。静态一致性、慢变边界/估计误差下 ISS；模型中的有界更新扰动不自动给未知区域覆盖误差界（pp. 5–7）。

三/四机器人非凸静态/膨胀曲线仿真，无实机；拓扑分裂列未来。理论中“慢变”和唯一投影要求应具体量化后再移用，噪声/离散化项不能当作已知证书（pp. 8–9）。对项目：沿未知非凸轮廓局部重建、加权插值点部署已有先例；新增方向应连接到作用能力/观测充分性，不能只改变覆盖密度。
