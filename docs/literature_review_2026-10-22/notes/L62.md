# L62 — Robust Control Barrier Functions using Uncertainty Estimation with Application to Mobile Robots

Ersin Daş, Joel W. Burdick；arXiv:2401.01881v3 (31 Jan 2025)。八 PDF 页正文文字已读；显示公式/原图待复核。

全状态可测/可估、输入已知、名义输入矩阵满列秩；未知动力学及其时间导数有界，噪声有已知界。指数滤波型观测器给统一最终有界误差，用估计与误差界鲁棒化 CBF，并可抵消匹配分量。直接余量版本依赖初始未知量幅值界；增广 Lyapunov 版本虽不显式用该幅值，仍要求初始状态在更小的误差相关安全集内、估计器快于屏障速率（pp. 2–5）。

HOCBF 扩展允许扰动比控制提前最多一阶出现，非仿射范数约束变为 SOCP；不是任意不匹配、任意相对阶都适用。输入补偿之后仍要满足实际输入界和过滤器可行性；连续时间 Lipschitz 结论不能直接替代数字保持段证明（pp. 5–6）。

弹性执行器仿真，界由多情境仿真选取。履带车 25° 斜面/局部地毯滑移实机，50Hz，已知墙/边缘几何，存在匹配及不匹配扰动。该例相对阶均一，未在实机验证更一般 HOCBF 情况。导数界数据学习与状态估计误差列未来（pp. 7–8）。

对项目：估计加鲁棒余量已有直接方法，关键缺口是 PCA/局部扫描误差界、接触切换的正则性与整体可行性；不能用经验质量分数代替已知界。
