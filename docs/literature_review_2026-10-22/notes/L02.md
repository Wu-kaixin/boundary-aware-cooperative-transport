# L02 — A self-adjusting and modular supervisory control algorithm for planar dexterous manipulation

Stefan Ristevski, Melih Cakmakci; Mechatronics 90 (2023) 102936; DOI 10.1016/j.mechatronics.2022.102936. PDF pp. 1–16正文通读，显示公式/原图待复核。

任务为接触推动下同时跟踪平移、转角与时间参考，允许操纵器滑移、位置变化和失效。已知接触点/相对质心位置和法向角；中心监督器测量物体位姿并广播总力、总力矩与配置参数（pp. 3–4, 7–8）。按接触角分配单边力，再分配转动力矩修正；局部两层位移/力反馈维持接触（pp. 4, 8）。不是无中心、纯局部观测的方案。

基于近似传递函数、同质操纵器及小扰动进行鲁棒稳定分析；设备数和差异增大使耦合/鲁棒性恶化（p. 9）。Matlab 与 MechaCell 实物，比较正常、±10°错配、单设备失效与选定 caging/tugboat 方案；实物重新整定 PID，报告 IAE（pp. 10–12）。不能把其特定 caging 比较推广为所有 caging 无法控制姿态。

对 DBACT：接触方向分配、维持接触、制动前的配置能力与动力学耦合均已有明确处理。潜在新增能力应是从未知局部边界自动获得这些操作条件并量化保障，而不是再提出定向推力或监督阶段机。
