# L45 — Distributed Receding Horizon Formation Control by Multiple Mobile Robots Using Voronoi-Based Coverage

Fateme Mohseni, Ali Doustmohammadi, Mohammad Bagher Menhaj；源 PDF 无明确卷期，现已由出版方核实对应 IFAC Proceedings Volumes45(7):103–108 (2012), DOI10.3182/20120523-3-CZ-3015.00022，正式稿内容差异待核。**六页原始渲染页面全部已逐页阅读（pp.1–6，含公式/图表可视检查）；证明独立验证未完成。** 原提取文本字体映射乱码，未把乱码计为已读；实际阅读副本为 `tmp/literature/L45-original-1.png` 至 `-6.png`。

已知凸域/密度编码指定几何形状，单积分器，邻居轨迹消息和同步 MPC 更新。定义自身到期望 CVT 质心与邻居相对位移的 coverage vector，二次成本/终端约束；用前轮解估计邻居轨迹，并施 compatibility constraint 限制真实与预期偏离（pp. 2–5）。

收敛证明多引自身 2012 学位论文；期望质心在推导中作为平衡配置，算法又每次重算质心，固定目标/移动分区接口需独立核对。Proposition 1 把零梯度称充分最优条件的表述也需区分一般 CVT 临界点。没有给任意局部噪声、延迟、实体碰撞或未知环境的完整保证。

20 点机器人三种密度（斜线、直线、椭圆区域）仿真，次秒收敛为模型/尺度结果，无硬件/接触物体。对项目：用密度定义形状、MPC 分散队形和兼容轨迹约束已有先例；需要证明实际局部地图/切换后的相容性，而非仅串接工具。
