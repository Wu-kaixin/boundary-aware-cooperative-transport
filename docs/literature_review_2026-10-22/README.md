- **已获取/已提取**仅代表文件可读，不代表研究者读完。

- **正文通读**保留逐页定位，但显示公式与原图尚未逐一复核。
- **全文文本已读**代表原始提取文本全部已读；图表、关键公式、证明独立核验分别记录。
