# Current finite support after acquisition: independent eight-episode protocol

This protocol implements the existing post_acquisition_finite_support_v1_spec.md
after its zero-new-physics publication checkpoint at0c7bf9f. The old checkpoint,
all18-state and272-state evidence, and earlier physical failures remain unchanged.

Question: does the empirical current finite-support path improve the full physical
task while preserving all best-known numeric settings and original safety/stop
contracts? Unit: one complete16-agent episode. Four reused development conditions:
near_circle, near_l_reference, far_c_open_away_pos0, far_skew_box_s0_r0_pos0.
Each condition receives two arms with the same old seed, initial state, 12000
frames at0.05s, settle settings and physics. map_bridge_control reproduces the
old map_bridge_candidate. post_support_candidate differs only by the boolean
post_acquisition_finite_support=True. Schedule seed20261103; four workers and one
internal thread. Maximum8episodes/96000steps; no wall-clock scientific cutoff.

Before execution bind old protocol/receipts/source, current source, helper closure,
environment, protected YAML, tests and initial hashes. No same-path rerun/resume,
no overwriting a freeze or physical attempt, no runtime edit during this study.
Analysis failures retain their own receipt and never cause physical reruns.

Use unchanged task/safety metrics: safe completion, valid zero epoch, falseHOLD,
hard safety violations, budget termination, G500, phase-specific scaling, formal
TRANSPORT, elapsed time, endpoint error and maximum actual rotation. Report every
matched adverse change. Full original controls must reproduce all saved arrays
and scientific fields. Audit all candidate controller frames and finite-support
inputs/rows, independently checking actual-command hard, capped and uncapped
residuals. Retain unsupported-state fallbacks. Truth stays in evaluation only.

Mechanism gates: unique complete8episodes; exact4controls; candidate4/4 safe with
valid zero epoch; no falseHOLD/hard failure/cutoff; matchedG500 preserved; no
acquisition or post-acquisition scaling increases; skew post-acquisition scaling
strictly reduced; C maximum rotation does not increase; finite-support audits
verified, candidate path actually exercised, all admitted hard rows satisfied.
Full-episode support audit completion and pair/bridge audit verification are
explicit gate fields; a20-frame audit prefix cannot satisfy episode verification.
Full gates additionally require zero candidate scaling, G5004/4, formalTRANSPORT
in all four and zero executed full uncapped admitted object-row violations.
The committed gate evaluator defines these checks without post-result changes.

This remains an empirical candidate: unknown unsampled continuations, stochastic
noise and true boundary velocity are not certified by local scans or received
motion. Even a passing pilot requires broader preservation/generalization and a
separate deployment-contribution comparison. Candidate stays defaultFalse.
